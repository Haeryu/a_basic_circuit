Shortcuts & tips

Drag a chip from the palette onto the canvas.

Pan with the wheel, middle drag, or Space + drag. Shift + wheel pans sideways.

Zoom with Ctrl + wheel. F fits the circuit.

Select with an empty-canvas box or Shift-click. Move selected chips together.

Copy / paste with Ctrl+C / V. Internal wires and custom definitions travel together.

Wire by dragging between pins. Select a wire for its floating color/delete controls.

Delete a wire with the floating ×, Delete/Backspace, double-click, or right-click.

Make chip replaces the selection with one reusable chip; boundary wires become interface ports automatically.

Double-click a custom chip to enter it on the same canvas. Use the breadcrumb, Esc, or Alt+↑ to return.

+ New starts a chip from scratch with compact IN/OUT rails. Custom chips can contain other custom chips.

Chip modules: mark palette chips with Pack, then Export them together as one NAME.abc-chips.json. Import loads only those reusable chip definitions, not the root circuit; shared nested dependencies are bundled once.

Esc cancels a drag before leaving the current chip scope. Drag a selection to the trash to delete.
